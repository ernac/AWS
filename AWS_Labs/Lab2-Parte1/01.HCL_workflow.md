# HCL - TERRAFORM WORKFLOW

## BASIC STRUCTURE

[Terraform Workflow Documentation](https://developer.hashicorp.com/terraform/intro/core-workflow)


>The core Terraform workflow has three steps:

- Write - Author infrastructure as code.
- Plan - Preview changes before applying.
- Apply - Provision reproducible infrastructure.

## INDIVIDUAL WORK

### WRITE

- You write as a regular code.
- You use a versioning tool.

```Python
# Write initial config
$ vim main.tf

# Initialize Terraform
$ terraform init

Initializing provider plugins...
# ...
Terraform has been successfully initialized!

```

- With time and practice you get to know the syntax better. Your config is coming together as you expected.

```Python
# Make edits to config
$ vim main.tf

# Review plan
$ terraform plan

# Make additional edits, and repeat
$ vim main.tf

```

- There is a useful feedback loop between editing code and running test commands.

### PLAN

>When the feedback loop pays off, it's time to commit your work and review the final plan.

```Python
git add main.tf
git commit -m 'Managing infrastructure as code!'
```
