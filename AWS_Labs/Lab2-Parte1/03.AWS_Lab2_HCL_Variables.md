
# TERRAFORM INPUT VARIABLES

>Input variables in Terraform serve as parameters for your infrastructure code, functioning like function arguments to make configurations reusable, dynamic and customizable across different environments, without modifying the core code.

## EXTERNAL REFERENCE
[Terraform Variables](https://developer.hashicorp.com/terraform/language/values/variables)

# DECLARING INPUT VARIABLES

```Python

# Variable declaration
variable "instance_type" {
  description = "EC2 instance size for the web application"
  type        = string
  default     = "t3.micro"
  sensitive   = false

# Validation conditions
  validation {
    condition     = contains(["t3.micro", "t3.small", "t3.medium"], var.instance_type)
    error_message = "The instance_type must be a valid t3 family type."
  }
}
```

- **`description`**: Documents the variable's intent and expected input.
- **`type`**: Restricts the accepted data type (primitives like `string`, `number`, `bool`, or complex types like `list`, `map`, `object`, `tuple`).
- **`default`**: Sets an optional fallback value; omitting this makes the variable mandatory.
- **`sensitive`**: When set to `true`, masks the value in CLI outputs, plans, and console logs (though it remains in plain text within state files).
- **`validation`**: Defines custom conditional checks and explicit error messages to enforce input rules prior to execution.
- **`nullable`**: Dictates whether `null` is accepted as a valid value (defaults to `true`).


# VARIABLE DEFINITION PRECEDENCE

When the same variable is supplied through multiple channels, Terraform resolves the final value using a strict hierarchy, evaluated from **lowest to highest priority**:

1. **Environment Variables:** `TF_VAR_<variable_name>` (e.g., `export TF_VAR_instance_type="t3.small"`).
2. **Standard Variable Files:** `terraform.tfvars` or `terraform.tfvars.json`.
3. **Auto-loaded Files:** Any `*.auto.tfvars` or `*.auto.tfvars.json` files (loaded in lexicographical filename order).
4. **Command-Line Variable Files:** Explicit `-var-file="custom.tfvars"` flags.
5. **Command-Line Key-Value Flags:** Direct CLI inline arguments using `-var="instance_type=t3.medium"` (highest priority; overrides all others).

# REFERENCING VARIABLES

Inside your configuration files, reference declared variables using the `var.<name>` syntax:

```
resource "aws_instance" "web" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = var.instance_type
}
```
